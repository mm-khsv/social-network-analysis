# Social Network Analysis

## Project Overview

This project presents a comparative analysis of three real-world and benchmark social networks using graph theory and network analysis techniques.

The main objective is to investigate network structures, understand the distribution of connections, evaluate node importance, and examine the recurrence of influential nodes across different centrality rankings.

## Networks and Datasets

Three network datasets are used in this project:

| Network     | Description                                                                          | Data Source                      |
| ----------- | ------------------------------------------------------------------------------------ | -------------------------------- |
| Karate Club | A social network representing friendships among members of a university karate club. | NetworkX / Zachary's Karate Club |
| Dolphins    | A social network representing associations among dolphins.                           | KONECT                           |
| Facebook    | A large-scale social network represented by an edge list.                            | Stanford SNAP                    |

### Dataset References

- **Dolphins Network:** https://networks.skewed.de/net/dolphins
- **Facebook Network:** https://snap.stanford.edu/data/egonets-Facebook.html
- **Facebook Dataset Download:** https://snap.stanford.edu/data/facebook_combined.txt.gz
- **Dolphins Network Reference Paper:** https://doi.org/10.1007/s00265-003-0651-y

## Analysis Components

The project consists of the following analytical components:

### 1. Network Properties

Calculation and comparison of fundamental structural properties of the three networks, including network size, number of edges, and other basic graph statistics.

### 2. Centrality Analysis

Evaluation of node importance using centrality measures and comparison of node rankings across the three networks.

### 3. Degree Distribution

Investigation and visualization of degree distributions to understand how connections are distributed among network nodes.

### 4. Network Visualization

Generation of network structure visualizations and comparative figures to provide a graphical understanding of network topology and structural differences.

### 5. Descriptive Statistics

Statistical analysis of network characteristics, including measures that describe the distribution and structural properties of each network.

### 6. Complementary Cumulative Degree Distribution (CCDF)

Analysis of the complementary cumulative distribution of node degrees using logarithmic scales.

### 7. Case Study and Rank Profiles

Examination of node rankings and their profiles to compare the behavior of centrality measures.

### 8. Centrality Recurrence Analysis

Investigation of repeated appearances of nodes across different centrality rankings and analysis of recurrence patterns.

## Installation and Setup

### Prerequisites

- Python 3.10 or newer
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/mm-khsv/social-network-analysis.git
cd social-network-analysis
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

### 3. Activate the Environment

For Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

## Running the Project

All commands should be executed from the project root directory.

Run the analysis scripts in the following order:

```bash
python src/analyze_network_properties.py
python src/analyze_centrality.py
python src/plot_degree_distribution.py
python src/generate_network_visualizations.py
python src/network_descriptive_statistics.py
python src/degree_ccdf.py
python src/case_study_rank_plot.py
python src/recurrence_plot.py
```

Some visualization scripts depend on CSV files generated by earlier analysis scripts. Therefore, following the execution order is recommended.

## Outputs

The project generates two main categories of outputs:

### Figures

The `outputs/figures/` directory contains the visualizations generated throughout the analysis, including:

- Network structure visualizations
- Degree distribution plots
- Centrality comparison figures
- Network descriptive statistics
- CCDF plots
- Case study rank profiles
- Centrality recurrence visualizations

### Tables

The `outputs/tables/` directory contains numerical and analytical results in CSV format, including:

- Basic network properties
- Centrality rankings
- Node-level centrality values
- Degree distribution data
- Centrality recurrence results
- Descriptive statistics

Previously generated figures and tables are also included in the repository for convenient inspection.

## Reproducibility

The source code, datasets, dependency list, and generated analytical outputs are provided to support transparency, reproducibility, and further investigation.

Users can reproduce the analysis by installing the required dependencies and executing the Python scripts from the project root directory.
